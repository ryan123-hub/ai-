# 歌词 → 场景分镜文本（画面生成前的硬门禁）

任何歌词 MV（水彩或像素）在写场景代码、渲接触片或成片之前，必须先产出一份**分镜文本**交给用户确认。分镜未通过前，禁止进入画面生成。

本文件是中间交付物的写法；时长/节拍/章节布局仍遵守 [music-video.md](music-video.md)；像素模式额外遵守 [pixel-lyric-mv.md](pixel-lyric-mv.md)。

## 何时写

在脚手架、`beat_grid.py`、创作方向确认完成之后；在 `src/scenes/*`、`LY` 填充之外的任何画面代码之前。

用户说「直接干 / 不用看分镜」时，仍要写完整分镜文件到磁盘，但可跳过等待确认。

## 交付物

项目根目录写 `STORYBOARD.md`（唯一权威）。同时把同一份内容（或精简版）发到对话里给用户审。不要只口头说「大概是这些镜头」。

## 必含块（按顺序）

```markdown
# <歌名> · 分镜

## 整片锁定
- **隐喻 / Logline：** 一句话，整片只服务这一个世界（不要每句换题材）
- **介质：** watercolor | pixel（pixel 时写明 lyricUI：ktvCaption | rpgBox，pixelGrid）
- **调性 / 调色弧：** 开头→副歌→结尾怎么变
- **固定角色：** 姓名、外形锁定点、整片情绪弧
- **反复母题：** 会回来并升级的道具/场景（伞、HP、花、同一条街…）
- **歌词方言：** 卡拉 OK 怎么出现；禁止在画面里再写一整句歌词
- **画面语言：** 屏上 HUD、特效字、招牌、标题卡与结束卡须与歌曲（或用户指定）语言一致，不要混用装饰性外文
- **词画对齐：** 每一行的画面必须贴合该句的场景、情绪与意象；镜头起止与 `LY`（及 LRC）对齐，不得在不改词轴的情况下漂移切镜
- **开场 / 收尾：** 标题卡与结束卡必须同字体气质、同语言，并与开场押韵

## 歌曲网格
- BPM / offset / 片段起止（clip time）
- 一行歌词大约几拍、几秒

## 章节
### C01 <段落名> · <场景设定> · <本章调色>
| Clip | 歌词 | 画面事件（背后场景） | 角色动作/反应 | 镜头 | 出镜转场 | 读点 reads |
|------|------|----------------------|---------------|------|----------|------------|
| 0.00–3.02 | （前奏） | … | … | … | iris | … |
| 3.02–6.07 | 第一句原文 | 这句词「演」成什么场面；地点、时间、天气、关键道具 | … | … | cut / dissolve / … | 0.0–1.2 先看懂 A；1.2–2.5 再看懂 B |
```

规则：

1. **一行歌词 ≈ 一个镜头**（约 1.4–4 s）。前奏、间奏、尾奏也要有行。
2. **「画面事件」必须是可拍的场景**，不是情绪形容词。坏：「很悲伤」。好：「雨夜站台，她背对镜头撑伞，霓虹在水洼里抖」。
3. **先演后标。** 场景把这句词的意思演出来；卡拉 OK 只负责出字，不要在场景道具上再抄整句。
4. **读点不重叠。** 每个 reads 写清起止；塞不下就加长镜头或减读点。
5. **每个接缝写出镜转场。** 水彩可用 brushWipe；像素用硬切 / 淡入淡出 / dither / 翻卡 / CRT，禁止笔刷擦除。
6. **章节 = 歌曲段落**，每章一个可复用场景；副歌应回到同一场景并升级，而不是换题材。

## 发给用户时怎么说

先交分镜，再问要不要改。示例口吻：

> 分镜写好了（`STORYBOARD.md`）。按 LRC 逐句对了场景，还没画。你看看隐喻、角色和逐句画面要不要改；确认后我再按镜生成。

用户只改某几行时，改表后再确认一次变更行，不要偷偷开画。

## 通过之后才做

1. 把表里的时间填进 `src/karaoke.js` 的 `LY`（文案以用户 LRC 为准，禁止臆造）。
2. 按章节建 `src/scenes/cNN_*.js`，一镜一事件，严格按表实施。
3. 接触片 / strip 对照分镜 reads 审查；分镜与成片不一致时先改分镜或先改画面，并在对话里说明。

## 最短检查清单

- [ ] 每句 LRC 都有一行，无空镜无跳句
- [ ] 每行都有具体地点 + 事件 + 出镜转场
- [ ] 整片只有一个隐喻；角色外形锁定
- [ ] 屏上语言文字与歌曲/用户语言一致（中文片无残留装饰英文）
- [ ] 无与该句矛盾的画面；切镜时间与 LY 对齐
- [ ] 用户已看到分镜文本（或明确授权跳过确认）
- [ ] 尚未写场景绘制代码 / 尚未全片渲染
